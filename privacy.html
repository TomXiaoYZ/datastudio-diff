Privacy Policy — Report Diff for Data Studio

Last updated: November 21, 2026

Report Diff for Data Studio saves report-definition snapshots on your device and shows what changed between them. This policy explains what the extension reads, stores and sends.

Report definitions

The extension reads only report-definition responses that the Data Studio (Looker Studio) page itself loads through getReport, createTempReport and getSchema. Its content scripts do not read request bodies, send requests to Google, or modify the report or page content. Choosing "Snapshot now" reloads the tab so the page can load its own definition again.

Snapshots can contain report, page and chart names; chart types; field names; filters; date-range and sort settings; data source names and identifiers; interactions; and styling properties. The extension does not read or store the data values shown in charts. Google account identifiers are removed when report definitions are normalized into snapshots.

Local storage and deletion

Report snapshots and extension settings are stored only in local extension storage in your browser on your device. Report definitions are not sent to the developer, ExtensionPay, Stripe or any other server. Snapshots are not synchronized between devices or shared with teammates.

You can delete saved report snapshots using "Clear all data" in Settings. Uninstalling the extension removes its local extension storage, including settings. Downloaded inventories and change lists are files you choose to save; deleting the extension does not delete those files.

Anonymous usage count

Anonymous usage count is off by default. It sends nothing unless you explicitly enable it in Settings and a counting address is configured in the extension. Version 0.1.0 has no counting address configured, so it sends no usage counts even if you enable the setting.

When enabled and configured, the first inventory download sends a single request containing only the event name (inventory_download) and the extension version. The request contains no user or installation identifier, report identifier, report data, email address or cookies. A local marker prevents further counts for that installation. Failed requests are not retried. You can turn the setting off at any time; doing so does not affect downloads. There is no other usage analytics, advertising or error reporting.

Payments and paid status

If you buy Pro or sign in to restore a purchase, ExtensionPay (https://extensionpay.com) and Stripe (https://stripe.com) handle the payment and email information under their own privacy policies. Card details are entered in their payment flow, not stored in report snapshots or handled by the extension's report features.

When the side panel opens, the extension contacts ExtensionPay to check whether you have paid. The bundled ExtensionPay library also handles payment completion and sign-in. Paid status is cached locally so the extension can apply the appropriate plan. Report definitions are never included in these requests.

The developer can access paying users' email addresses and payment status through ExtensionPay to provide the purchase and respond to support requests. This information is not used for advertising or unrelated tracking. Review the providers' privacy policies in their payment and sign-in flows.

Data use

We do not sell personal information or report data. Data is used only to provide the extension's stated functionality, process and restore purchases, and respond to support requests. Payment providers process the information needed for those services. Report data is not transferred to them.

Limited Use

The use of information received from Google APIs and Google web pages adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
